# Akkaripattu DayTrail — Simple Starter

A beginner-friendly React + Vite starter website for the Akkaripattu DayTrail project.

## Features
- 10 preliminary places from the project proposal
- Search places by name
- Filter by category
- Add/remove places from a simple one-day plan
- General OpenStreetMap embed for Akkaraipattu
- Responsive layout

## Run on Windows
1. Install Node.js if needed.
2. Extract this ZIP.
3. Open the `Akkaripattu-DayTrail` folder in File Explorer.
4. Click the address bar, type `cmd`, and press Enter.
5. Run these commands:

   npm install
   npm run dev

6. Open the local address shown in the terminal, usually http://localhost:5173.

## Important
This is a frontend starter. It does not have an Express/MongoDB backend or permanent itinerary storage yet. Place details and distances are preliminary; verify them before submitting the report. The map is a general area map, not verified individual place pins.
